# Fonts

Both typefaces are free and open-licensed (SIL Open Font License 1.1).

| Typeface | Weights used | Download |
| --- | --- | --- |
| Sora | 400, 600, 700 | https://fonts.google.com/specimen/Sora |
| JetBrains Mono | 400, 500 | https://fonts.google.com/specimen/JetBrains+Mono (also https://www.jetbrains.com/lp/mono/) |

Web embed:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Sora:wght@400;600;700&family=JetBrains+Mono:wght@400;500&display=swap">
```

The logo files are outlined artwork, so they never need these fonts installed.
